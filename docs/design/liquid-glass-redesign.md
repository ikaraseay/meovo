# 液态玻璃桌面 · 重新设计方案

> 废弃上一版「瑞士国际主义」平面风格（直角、Helvetica、顶部 4px 红线、编号章节），
> 保留并强化**液态玻璃**，把整站做成一块可自由摆放的「玻璃工作台」。

## 1. 视觉方向

- **极光背景**：视口背后四团色斑（暖橙 → 珊瑚粉 → 紫罗兰 → 金黄）缓慢游移，
  毛玻璃折射的就是这层光。深色模式换更深的一组。
- **圆角玻璃**：全站从直角改成 10 / 16 / 22 / 28px 的圆角刻度，卡片都是通透的
  `blur + saturate` 毛玻璃，带一圈 1px 高光描边 + 内顶高光 + 柔和投影，hover 轻轻抬起。
- **随机浅底色**：每张卡片按 id 哈希到一个悦目色相（避开病态黄绿），
  盖在毛玻璃之上，浅到「感觉得出来一点就好」（约 30% 透明度）；深色模式用更深的一组。
- **两档玻璃**：
  - **真液态玻璃（折射 + 色散）**只给「招牌」—— 悬浮栏、二级面板、玻璃镜片、设置 FAB/弹窗。
    走已有的静态滤镜 `#glass-refract`。
  - **普通毛玻璃（仅 blur + saturate）**给普通卡片/列表部件。折射的 `feDisplacementMap`
    开销大，铺满整页会掉帧；毛玻璃已足够「玻璃感」。
- **主色**沿用火焰橙；个性靠轻微倾斜、可拖拽、随机浅色来给。

## 2. 可拖拽部件系统（核心）

所有页面元素都成为「玻璃部件（widget）」，桌面端可以抓起自由摆放，位置跨页跨刷新还原。

- **部件**：`GlassWidget.astro` 包一层玻璃卡片，顶部抓手是**跟设置弹窗同款的白色小横条**，正文走 slot。
- **状态**：`frontend/lib/widget-state.ts` —— 按 `widget id` 存**百分比坐标** `{xPct, yPct, pinned}`，
  坏值丢弃；窗口尺寸变化时按百分比等比还原（未固定相对桌面、固定相对视口）。
- **引擎**：`frontend/lib/draggable.ts` —— 三种默认布局：
  - **散开模式**（默认）：间隔宽松的瀑布流（顶部预留 10% 给悬浮栏）→ 自由拖拽。
  - **内容锚定模式**（`data-desk-flow` + `[data-desk-content]`）：正文留在文档流、
    卡片绝对定位在四周（top/side/tail），拖卡片不影响正文 —— 文章页用。
  - **流动模式**（`data-desk-flow` 无 content）：卡片留在文档流，拖一下才抬起来 —— 页脚用。
  - `data-widget-full` 的部件独占一行。
- **层级**：点谁谁到最前 —— 按点击顺序递增 z-index，被盖住的卡片点一下就浮上来，
  且永远低于悬浮栏。
- **固定（pin）**：点卡片右上角的图钉 📌 → 固定为 `position: fixed`、跟随视口滚动；
  再点 → 取消，回到绝对定位。适合思维导图 / 目录这类想一直看到的卡片。
  固定卡片仍可拖动，且不受散开 / 「重置布局」影响。状态持久化（`pinned`）。
- **加载**：布局完成前桌面先藏起（`html.js` + CSS），摆好后补 `.desk--ready` 淡入；
  布局期间 `.is-laying-out` 关掉部件过渡，避免「抖动」。
- **降级**：移动端（<1024px）或 JS 失效时，部件退回正常文档流，单列可读；
  无 JS 时内容照常可见（SEO / 可访问性不受影响）。
- **重置**：设置弹窗里的「重置卡片布局」，清空位置与固定、重新撒开 / 归位。

## 3. 内容布局（借鉴 hakadao.cc 的个人博客骨架）

- **首页** = 桌面：Hero 问候部件（宽）+「关于我」名片部件 + 每篇文章一张可拖拽卡片。
- **归档 / 标签 / 分类 / 系列 / 友链 / 关于**：页头与内容块各自成为玻璃部件，
  桌面端可拖拽，移动端单列。
- **文章页**：正文是正常文档流（位置不变、不被卡片占位），标题/目录/结构图/
  上一篇下一篇/翻译页脚都是绝对定位的可拖拽卡片，默认落在正文四周
  （标题在上、目录与结构图在右、导航与页脚在下），拖卡片不引起正文重排。
- **页脚**：也是一张可拖拽的玻璃卡片，流动模式默认待在页面底部，但也能拖走。

## 4. 技术守则（不变）

- 颜色全走 `--ui-*` token；组件 scoped 样式不写 `background / border-radius / box-shadow`。
- `backdrop-filter` 只写标准属性（不写 `-webkit-` 前缀）。
- 折射能力仍由 `BaseLayout` 首屏内联脚本判定，`html.glass-refract / .glass-fallback`
  三处（内联脚本 / `liquid-glass.ts` / `tokens.css`）对得上。
- 文案一律 `t()`，新词条中英齐备；界面以文字为主，少用图标。
